## What is PlayRex?

PlayRex is an intelligent automation system designed to transform long-form gaming videos and livestreams into engaging YouTube Shorts automatically.

**PlayRex = Gaming YouTube Channel + AI-Powered Shorts Production Pipeline**

### Project Overview

PlayRex simplifies content creation for gaming channels by:
- 🎯 **Detecting** the best gameplay moments automatically
- ✂️ **Editing** clips with precision
- 🔄 **Converting** to vertical format (9:16)
- 📝 **Adding** subtitles intelligently
- 🏷️ **Generating** titles, descriptions, and hashtags
- 📤 **Uploading** directly to YouTube Shorts

### The Goal

**One long gameplay video → Fully automated production → Multiple YouTube Shorts → Published automatically**

### Target Channel

- **Channel Name:** PlayRex
- **Content Focus:** Gaming, PlayStation 5 gameplay (Battlefield 6, etc.)
- **Format:** YouTube Shorts (vertical videos, 15-60 seconds)

## How It Works (Planned)

1. **Input** → Long gaming video or livestream
2. **AI Analysis** → Find high-action moments, excitement peaks
3. **Editing** → Auto-edit, trim, optimize
4. **Enhancement** → Add subtitles, effects, text overlays
5. **Metadata** → AI-generated titles, descriptions, hashtags
6. **Publishing** → Auto-upload to YouTube Shorts

## Technology Stack

- **Language:** Python 3.8+
- **AI/ML:** Video analysis and moment detection
- **Automation:** YouTube API integration
- **Video Processing:** Frame-by-frame analysis, vertical format conversion
