# Contributing to PlayRex

Thank you for your interest in contributing to PlayRex! We welcome feedback, suggestions, and contributions from developers of all levels.

## How to Contribute

### 1. Report Issues 🐛
Found a bug or have an idea? Open an issue!
- Describe the problem clearly
- Include steps to reproduce (if applicable)
- Suggest a solution if you have one

### 2. Suggest Features 💡
Have an idea to improve PlayRex?
- Open an issue with the "enhancement" label
- Explain the use case
- How it would benefit the project

### 3. Start a Discussion 💬
Questions or ideas for the project?
- Use GitHub Discussions
- Share your thoughts
- Learn from the community

### 4. Submit Code 🔧
Want to submit code?
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/AmazingFeature`)
3. Make your changes
4. Commit your changes (`git commit -m 'Add AmazingFeature'`)
5. Push to the branch (`git push origin feature/AmazingFeature`)
6. Open a Pull Request

## Code Style

- Follow PEP 8 guidelines
- Add comments for complex logic
- Update documentation as needed
- Test your changes before submitting

## Development Setup

```bash
# Clone the repository
git clone https://github.com/umtcnkrky/PLAYREX_BOT.git

# Install dependencies
pip install -r requirements.txt

# Create a config file
cp config.example.py config.py

# Run the application
python playrex.py
```

## Questions?

Feel free to:
- Open an issue
- Start a discussion
- Contact the maintainers

We're all learning together! 🚀
